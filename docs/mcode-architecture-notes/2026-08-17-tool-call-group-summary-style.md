# 工具调用分组摘要样式契约

会话详情中的 `ToolCallGroupBlock` 使用固定基础类 `tool-group__summary`，半透明模式只额外添加 `tool-group__summary--translucent` 背景修饰。基础摘要和半透明变体均不绘制边框，以保持与无边框 assistant 气泡一致的视觉层级。

原生复刻时，工具调用分组应作为中性、紧凑、可展开的摘要控件：状态颜色继续由单个工具调用条目承载，分组标题不应因完成/失败状态改变成强调色或出现额外边框。颜色使用既有 uview `--up-*` 运行时变量对应的原生主题色，不引入新的 MCode 色彩别名。

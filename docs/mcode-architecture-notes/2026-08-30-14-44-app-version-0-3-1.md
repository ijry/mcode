# mcode-app 版本升级至 0.3.1

## 架构与数据流

应用发布版本统一从 `0.3.0` 升级为 `0.3.1`。`mcode-app/package.json` 作为包元数据、`src/manifest.json` 的 `versionName` 作为 uni-app 原生构建版本、`src/services/appVersion.ts` 的 fallback 作为运行时信息不可用时的兜底，三处保持一致；`versionCode` 继续为 `3`。

关于页和 Android 更新检查继续优先读取 `uni.getAppBaseInfo()` 的运行时版本，只有运行时接口不可用时才使用 fallback，因此不会改变现有构建时间后缀或更新协议格式。

## UI 行为

关于页版本展示从 `v0.3.0...` 变为 `v0.3.1...`；Android 更新检查请求中的 `version` 参数及更新弹窗标题同步使用 `0.3.1`。

## 兼容性

版本号是展示和更新检查的元数据变更，不改变 API 路由、鉴权、持久化数据或连接协议。`versionCode` 保持 `3`，服务端应继续按既有 appbeta 版本检查规则处理。

## 原生 iOS/Android 复刻

原生客户端发布配置应将用户可见版本名设置为 `0.3.1`，内部版本号仍设置为 `3`，并在无法读取系统运行时版本时使用 `0.3.1` 作为 fallback。更新检查请求继续传递运行时版本名和 `versionCode`，不需要迁移本地数据或调整协议。
